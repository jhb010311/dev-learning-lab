이 사이트의 실습은 자바스크립트를 켜야 움직입니다. 아래는 같은 내용을 글로 적은 것입니다.

공부

Java

문법부터 객체 지향, 컬렉션, 스레드, JVM까지. 코드가 실행될 때 안에서 무슨 일이 일어나는지를 봅니다.

기본 문법

  • 변수와 타입 — 변수를 다른 변수에 대입하면 무엇이 복사되나
  • 연산자와 형변환 — 7 / 2는 왜 3.5가 아니라 3이 나오나
  • 조건문과 반복문 — 반복문은 몇 번 돌고, 어디에서 멈추나
  • 배열 — 배열 변수를 대입하면 배열이 복사되나

클래스와 객체

  • 클래스, 객체, 생성자 — new를 하면 어떤 순서로 무슨 일이 일어나나
  • static과 인스턴스 — b만 건드렸는데 왜 a의 값도 바뀌나
  • 상속과 오버라이딩 — 자식 객체를 만들 때 부모 생성자는 언제 실행되나
  • 다형성과 메서드 선택 — 어느 메서드가 실행될지는 누가, 언제 정하나
  • 인터페이스와 추상 클래스 — 둘 다 new로 못 만드는데 무엇이 다른가
  • 접근 제어자와 캡슐화 — private, protected, public은 어디까지 열어 주나
  • 내부 클래스와 익명 클래스 — 클래스 안에 만든 클래스는 바깥 객체와 어떻게 이어져 있나
  • 불변과 방어적 복사 — final을 붙였는데 값이 바뀌었다
  • 전략 패턴 — 결제 수단이 하나 늘 때 고쳐야 하는 곳

자주 쓰는 클래스

  • ==와 equals — 같은 값인데 ==는 왜 false가 나오나
  • equals와 hashCode — equals만 고치면 왜 HashMap에서 못 찾나
  • String, StringBuilder — 문자열 메서드를 불렀는데 왜 원본이 그대로인가
  • 날짜와 시간 — 1월 31일에 한 달을 더하면 며칠이 되나
  • Optional — 값이 있는데도 orElse의 기본값 코드는 왜 실행되나

예외

  • 예외와 finally — 예외가 나면 어느 블록이 어떤 순서로 실행되나
  • 체크 예외와 언체크 예외 — 어떤 예외는 왜 처리하지 않으면 컴파일조차 안 되나

제네릭, 열거형, 애너테이션

  • 제네릭 — List<Integer>의 <Integer>는 무엇을 막아 주나
  • 열거형(enum) — @Enumerated(EnumType.ORDINAL)로 저장한 enum은 왜 다른 상수가 되어 돌아오나
  • 애너테이션 — @를 붙이기만 하면 정말 무슨 일이 일어나나

컬렉션

  • ArrayList와 LinkedList — 같은 연산인데 드는 일의 양이 다르다
  • HashMap 내부 — HashMap은 키를 어디에 넣고 어떻게 찾나
  • Set과 Map의 종류 — 같은 값을 넣었는데 꺼내는 순서가 왜 다른가
  • 스택·큐·우선순위 큐 — 넣은 순서와 꺼내는 순서
  • 순회 중 삭제 — 반복문 안에서 원소를 지우면
  • 정렬과 Comparator — 정렬 순서는 누가 정하고, 빼서 비교하면 왜 틀리나

람다와 스트림

  • 람다와 함수형 인터페이스 — 람다에 적은 코드는 언제 실행되나
  • 스트림 지연 평가 — 스트림은 적힌 순서대로 실행되지 않는다
  • 스트림으로 모으기 — 스트림의 결과를 어떤 모양으로 모으나
  • 병렬 스트림과 공용 풀 — 남의 병렬 스트림 때문에 내 코드가 느려진다

스레드와 동시성

  • 프로세스와 스레드 — 일꾼을 늘리는 두 가지 방법
  • 스레드의 생성과 상태 — run()을 직접 부르면 왜 새 스레드가 생기지 않나
  • 경쟁 상태 — count++는 왜 숫자를 잃어버리나
  • 교착 상태 — 서로 기다리다 둘 다 멈춘다
  • 스레드 풀 — 스레드를 늘리면 무엇이 달라지나
  • 스레드 수와 컨텍스트 스위칭 — 스레드를 늘린다고 계속 빨라지지는 않는다
  • 순차 호출과 병렬 호출 — 외부 호출 여러 개를 차례로 할까 한꺼번에 할까
  • 블로킹·논블로킹·가상 스레드 — 기다리는 동안 스레드는 무엇을 하나

JVM

  • 스택과 힙 — 메서드를 부를 때마다 메모리에서는 무슨 일이
  • GC와 메모리 누수 — 버려진 객체는 누가 언제 치우나
  • JIT 워밍업 — 배포 직후의 첫 요청들은 왜 느린가
  • 클래스 로딩과 초기화 — 클래스의 static 블록은 언제 실행되나

입출력

  • 입출력 스트림과 버퍼 — write를 했는데 왜 파일이 비어 있나
  • 직렬화 — 저장한 객체를 되살리면 무엇이 돌아오나
