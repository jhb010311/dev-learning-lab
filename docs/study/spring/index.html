이 사이트의 실습은 자바스크립트를 켜야 움직입니다. 아래는 같은 내용을 글로 적은 것입니다.

공부

Spring

컨테이너와 의존성 주입, AOP와 트랜잭션, 웹 요청이 처리되는 길, 스프링 부트가 대신 해 주는 일을 봅니다.

IoC 컨테이너와 DI

  • 스프링 컨테이너와 빈 — new를 쓰지 않았는데 객체는 누가 만들어 넣어 주나
  • 빈 생성과 주입 — 스프링은 객체를 어떤 순서로 만들고 연결하나
  • 싱글톤 빈과 상태 — 내 주문에 다른 사람 이름이 찍혔다
  • 빈 스코프 — 프로토타입 빈인데 왜 객체가 하나뿐인가
  • 빈 생명주기 콜백 — 생성자에서 주입받은 필드를 썼더니 왜 null인가

AOP와 프록시

  • 프록시와 자기 호출 — 애노테이션을 붙였는데 왜 동작하지 않나
  • AOP: 어드바이스와 포인트컷 — 어드바이스는 어느 메서드에, 어떤 순서로 끼어드나

데이터 접근과 트랜잭션

  • 트랜잭션 기본 — 출금은 됐는데 입금이 안 됐다면
  • 트랜잭션 전파 — 예외가 나면 어디까지 롤백되나
  • JdbcTemplate과 예외 변환 — JdbcTemplate은 무엇을 대신 해 주고, 예외를 무엇으로 바꾸나
  • 커넥션 풀과 OSIV — 쿼리는 금방 끝났는데 커넥션이 모자란 이유

웹 MVC

  • 서블릿 — HTTP 요청이 자바 코드에 닿기까지
  • MVC 요청 흐름 — 요청 하나가 컨트롤러에 닿기까지, 그리고 돌아가기까지
  • 요청 매핑과 파라미터 바인딩 — 요청에 실어 보낸 값은 어떻게 메서드의 파라미터가 되나
  • 검증 — 필드에 @NotBlank를 붙였는데 왜 빈 값이 그대로 들어오나
  • REST API와 메시지 컨버터 — 컨트롤러가 돌려준 객체는 어디서 JSON이 되나

스프링 부트

  • 스프링 부트 자동 설정 — 의존성만 추가했는데 왜 빈이 생기나
  • 설정 우선순위 — 같은 설정이 여러 곳에 있으면 어느 값이 이기나
  • 액추에이터와 헬스 체크 — 결제사 연결이 끊겼을 때 헬스 체크는 무엇이라고 답하나

그 밖의 기능

  • 테스트 — 테스트를 실행할 때 스프링 컨텍스트에는 무엇이 들어가고, 몇 번 만들어지나
  • 외부 API 호출과 타임아웃 — 다른 서버를 호출했는데 답이 오지 않으면 언제까지 기다리나
  • 캐시 추상화 — @Cacheable을 붙이면 메서드 본문은 언제 실행되지 않나
  • 시큐리티 필터 체인 — 401과 403은 어디에서 갈리나
